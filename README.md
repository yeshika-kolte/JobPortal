# 💼 Job Portal – MERN Stack

A full-stack **Job Portal web application** built using the MERN stack.  
The application allows users to explore job opportunities and provides functionality for managing job-related data through a modern web interface.

## 🚀 Features

- 🔐 User Registration & Login
- 👤 User Profile Management
- 💼 Browse Available Jobs
- 🔎 Search and Filter Jobs
- 📝 Apply for Jobs
- 📋 Manage Job Applications
- 🏢 Job Posting & Management
- ✏️ Edit and Delete Job Posts
- 📱 Responsive User Interface
- 🔄 REST API Integration
- 🗄️ Database Management

## 🛠️ Tech Stack
